# Figure 4-4 source note

`fig4_4_bandwidth.csv` records the numerical values supplied by the repository author for this revision. The values were described as a transcription of simulated and measured impedance-bandwidth results from the author's thesis for five reactively loaded cases tuned near 800 MHz.

The thesis PDF, full bibliographic citation, and exact page, figure, or table locator are not present in this repository. The public figure caption states that limitation rather than implying a more precise provenance than the available source supports.
